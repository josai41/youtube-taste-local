Support

Get help, ask questions, or report issues with YouTube Taste Local.

Contact and bug reports

Please contact us through GitHub Issues. Include the affected page, steps to reproduce the problem, and your Chrome version when possible.

Open GitHub Issues

Resetting data

The extension settings let you delete watch history, title-token ratings, channel ratings, automatically learned data, or all locally stored learning data.

Compatibility

This extension depends on YouTube's page structure. Changes made by YouTube may temporarily affect its operation.

データのリセット

拡張機能の設定画面から、視聴履歴、トークン評価、チャンネル評価、手動評価以外のデータ、または全学習データを削除できます。

対応範囲

本拡張機能はYouTubeの画面構成に依存します。YouTube側の変更により一時的に動作しなくなる場合があります。
